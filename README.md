# 浮生 · Tiny Eden

一个会自己演化的微观生态缸。打开网页，就像在屏幕里养了一整个小宇宙。

缸里的小生命有自己的基因、身体状态和性格。它们觅食、躲避、求偶、产卵、老去，
把基因传给下一代。突变会让它们一点点变样，选择会决定哪些样子留下来。没有任务，
也没有输赢。你能做的只是调一调环境，偶尔撒一点食物，然后看着这个世界自己写下它的故事。

## 第二版：育种收集 × 生态关卡

第二版把生态缸做成一个可以玩的游戏，分两种玩法：在自己的水缸里育种收集，以及挑战生态关卡。

- **多个水缸**：在顶部切换；生物可以带着自己的故事搬家；离开时水缸继续演化，回来时补上并告诉你发生了什么。
- **配对**：给两只生物牵线，先看孩子们大概会是什么样（基于真实的遗传计算），结成伴侣后它们只会去找对方。
- **委托**：住在水缸附近的人想要各种生命，或者希望水缸达到某种样子；委托都取自你水缸里真实的生命，一定做得到。把符合要求的生命交出去，就能得到灵光。
- **灵光商店**：基因透镜（看见隐性基因和稀有概率）、育种缸（没有掠食者的小水缸）、更多水缸和生命卡格子、新的生命和水草种子。
- **生命卡**：把喜欢的生命存成基因卡，以后在任意水缸复苏成一颗卵；也可以放生。
- **新手引导**：第一次打开时，有几步轻轻的引导。
- **生态挑战**：从停靠栏的「生态挑战」进入。第一章「浅滩」共 8 关，每关一个生态难题，按顺序解锁：
  1. 饥饿的小鱼：喂食。
  2. 春水初暖：调节水温。
  3. 拯救金色：用基因透镜找出隐性携带者，配对。
  4. 不速之客：放生闯入的掠食者。
  5. 湖蓝之梦：选育，让湖蓝色占多数。
  6. 寒潮将至：看懂预警，提前应对。
  7. 荒年：用好"生态繁荣"。
  8. 浅滩的考验：前面的本领综合起来用。

  每关的工具和次数都有限，有时限（按模拟时间算，可以加速）。完成目标得一颗星，做得更好再得两颗，星星会换成灵光。完成第 3 关后，每天还有一个按日期生成的每日挑战。挑战期间，你的水缸照常生活，回去时会补上这段时间。
- **新的身体**：商店里可以买到三种新生命。它们和鱼不能配对，体型代代相传、不会突变。
  - 水母：一张一缩随水漂，从水里滤食；带刺，掠食者不饿极了不碰它。
  - 小虾：贴着缸底活动，专吃沉下来的碎屑，繁殖很快。
  - 螺：只在缸底爬，啃水草根、苔藓和菌丝，壳硬得掠食者咬不动。
- **装饰**：买下以后点击缸底放下，在「世界与设置」里可以收起。
  - 岩洞：小生命躲进去不容易被发现，夜里爱在里面休息。
  - 暖石、冷石：让周围的水暖或凉七八度，冷热难受的生命会聚过去。
  - 水灯：日夜照着附近的水草和藻类。
- **新植物**：
  - 苔藓：在缸底慢慢蔓延，是螺和小虾的食物，也给贴底的小生命打掩护。
  - 发光海葵：夜里发光，不能吃，小生命爱躲进去过夜，偶尔分出新的一株。
- **新的生态区**：在商店解锁后，新水缸可以选择：
  - 寒冷深渊：又冷又暗，生命耐寒、夜里活动，苔藓铺地，海葵和水母点亮黑暗。
  - 暖光珊瑚礁：温暖明亮，生命颜色鲜艳，珊瑚和海葵丛里藏着小虾。
- **奇迹的时刻**：一种稀有特征第一次出现时，时间会放慢几秒，镜头跟住那只新生命，并弹出一张发现卡片，可以顺手关注它的一生。完成委托、解锁、拿到星星都有轻轻的提示音（打开声音时）。
- **生命图鉴**，分三页：
  - 这个水缸：本缸出现过的奇迹。
  - 全部收藏：所有水缸里见过的稀有特征、身体、水域和族群，以及收藏完成度。
  - 成就：24 个成就，都来自真实的游玩，每达成一个奖励一点灵光。

## 快速开始

需要 Node.js 20 或更高版本（开发时用的是 Node 22）。

```bash
npm install
```

```bash
npm run dev
```

然后在浏览器打开终端里显示的地址（默认 http://localhost:5173）。

其他命令：

```bash
npm run build      # 类型检查 + 生产构建，输出到 dist/（纯静态文件，可离线运行）
npm run preview    # 本地预览构建结果
npm test           # 单元测试（Vitest）
npm run typecheck  # 只做类型检查
npm run sim -- --seed eden --hours 6 --report 30 --watch 3   # 无头长时模拟
npx tsx scripts/levels.ts --seeds 4   # 让两个机器人玩每一关：什么都不做应该输，按设计思路玩应该赢
```

`dist/` 是纯静态文件，放到任何静态服务器上都能运行，运行时不依赖网络。

### 网址参数

| 参数 | 作用 |
|---|---|
| `?seed=任意文字` | 打开用这个种子长成的水缸；还没有的话就新建一个（同一个种子，开局总是一样） |
| `?new` | 新建一个随机水缸 |
| `?wallpaper` | 纯净壁纸模式：隐藏全部界面，默认开启节能模式（30 帧） |

不带参数打开时，会回到你上次看的那个水缸，并补上你不在期间流逝的时间。

## 怎么"养"

你不能直接控制任何一只生物，只能改变环境：

- **点选生物**：打开观察卡，可以看它此刻的状态、基因、一生和家族。
- **点击空白处**：撒一小撮食物；**长按**：持续撒。
  食物有三种：营养颗粒（下沉）、高能食物（沉得更快）、发光孢子（向上漂，落地后长出发光菌）。
  选"仅观察"时，点击空白处不会投喂。
- **灾害**：暴雨、寒潮、热浪、流星（点击水中选落点）、生态繁荣。每一种都有真实的模拟效果，结束后会根据实际数据写一份总结。
- **环境**：光照、营养丰富度、温度、自然突变概率；"高级"里还能调总量上限、植物生长和分解速度等生态参数。
- **时间流速**：0.5× / 1× / 2× / 5×，也可以暂停。

鼠标移到屏幕底部，控制坞会慢慢浮现。

| 快捷键 | 作用 |
|---|---|
| `H` | 隐藏 / 显示全部界面 |
| `F` | 全屏 |
| `M` | 打开 / 关闭环境声音 |
| `空格` | 暂停 / 继续 |
| `1`–`4` | 流速 0.5× / 1× / 2× / 5× |
| `Esc` | 取消瞄准、关闭面板、取消选中，或恢复被隐藏的界面 |

### 当作桌面壁纸

用 `?wallpaper` 打开就是一块安静的生态缸，没有任何界面元素，鼠标静止 3 秒后也会隐藏。
想让它真正待在桌面上，可以借助"把网页设为壁纸"的工具：macOS 用 [Plash](https://github.com/sindresorhus/Plash)，
Windows 用 [Lively Wallpaper](https://github.com/rocksdanister/lively)。
这个项目本身不会把一个普通的全屏窗口伪装成系统壁纸；真正的桌面层窗口留给下面"macOS 路线"里的原生外壳来做。

## 这个世界是怎么运转的

**食物链与物质循环**：光 → 水草、藻类、发光菌 → 小型草食生命 → 少数大型掠食者 → 尸体和碎屑 → 分解成营养 → 回到水草。
全世界只用一种物质单位，所有转移都记在账上；测试会检查物质严格守恒（误差小于 1e-9）。

**生物**：每只生物都有 23 个连续基因（体型、速度、感知、代谢、寿命、繁殖策略、攻击、防御、社交、好奇、胆小、活跃、夜行、适温、食性、体色、饰色、亮度、体长比、尾、鳍、触须、眼睛），
外加 7 个二倍体稀有基因座。每个基因都有收益也有代价，比如体型大更耐寒、能吃更大的猎物，但代谢更贵、成熟更慢，所以不存在"全面升级"的进化方向。
基因决定外形，也决定行为：每只生物用效用评分加状态机来决定此刻要漫游、探索、觅食、进食、休息、逃跑、追猎、求偶还是社交。

**遗传**：有性繁殖，基因来自双亲（部分直接继承，部分混合），小概率高斯突变，极小概率"大突变"。
遗传距离越远越难繁殖，族群会自然分化成新物种。默认参数下，大约每小时 7–8 代。

**稀有基因**：金色身体、半透明身体、双尾、多触须、荧光纹路、特殊眼睛（星瞳、三目、月牙瞳、异色瞳）、彩虹渐变。
它们是真正可遗传的基因，遵循孟德尔规律（显性、隐性、不完全显性），不会带来额外的生存优势：金色更显眼，半透明更脆弱，双尾更费力。
隐性特征可能藏在携带者身上很多代，然后在两个携带者相遇时重新出现。

**平衡**：资源有限、能耗随体型和速度增长、拥挤会抑制繁殖、掠食者有领地上限、猎物能躲进水草。
允许繁荣、衰退和局部灭绝；如果消费者全部消失，沉睡的孢子会用基因库里留下的基因重新孕育生命，并记进编年史。

## 三个灵魂功能

**生命的一生**：在观察卡上按 ☆ 关注一只生物，或者给它取个名字。从那一刻起，它的出生地点和父母、第一次进食、第一次成为父母、孩子的数量、
经历过的灾害、从掠食者口中逃脱、老去、死亡和死因，都会写进它的时间轴。它离开以后，故事还会继续：它的血脉延续到第几代后裔、何时断绝。
所有被关注的生命都收在"生命档案馆"里；世界的第一个孩子、最长寿的生命、子女最多的生命、某个族群的最后一只，即使没人关注，也会被自动收录。
关注的血脉会通过双亲向后代传递标签，配合"溯祖剪枝"的谱系存储，几十代之后仍能从任何一个后代追溯回最初的那一只，并画出家族树。
跟随镜头的生物死去时，会提示"继续跟随它的孩子"。

**世界编年史**：世界诞生、第一个后代、第一次突变、优势族群更替、家族延续 20 代以上、第一次物种灭绝、灾害造成的大量死亡、稀有基因的出现、扩散、消失与回归……
都由模拟里的检测器根据真实数据触发，不会有编造的事件。编年史叠加在人口曲线上，可以按 1 小时 / 24 小时 / 7 天 / 全部查看，
也可以在模拟时间和真实时间之间切换，还能按类别筛选。

**生命图鉴**：某种稀有特征（或特征组合）第一次在这个世界出现时，会安静地记下首例个体的名字、世代、时间和基因组，并用基因组画出它的样子。
图鉴会显示累计出现过多少只、现在还有多少只、它消失和重新出现的次数。只展示真正出现过的条目，不做收集任务。

## 存档

- 你可以同时养几个水缸（默认最多 3 个），在顶部切换；生物可以带着自己的生命故事搬到另一个水缸。
- 玩家档案（水缸列表等）和每个水缸都保存在浏览器本地的 IndexedDB 里：每分钟自动保存一次，切到后台和关闭页面时也会保存。浏览器禁止存储时会退化成内存存储，并提示你导出备份。第一版留下的世界会自动变成你的第一个水缸。
- "世界与设置"面板里可以给水缸拍快照、回到快照、改名、放下水缸、新建水缸（可以指定种子）、让水缸从头开始，导出文件或把文件导入为新水缸。
- 存档包含完整的世界：随机数状态、所有生物和环境网格，以及全部历史（编年史、日志、多分辨率统计曲线、谱系、生命故事、图鉴、家族、物种、基因库）。
  读档后，世界会按完全相同的方式继续演化（有测试保证）。
- 历史数据都有上限，长时间运行也不会无限增长：日志 300 条，编年史 3000 条（重大事件永久保留），统计曲线是 4 级降采样的环形缓冲，谱系只保留需要的节点。
- 离开时水缸不会停：页面关闭、切到后台或去看别的水缸时，回来会在 Web Worker 里补上你离开的时间（最多 2 个模拟小时，可以跳过），然后告诉你"你不在的时候"发生了什么。设置里可以关掉。

## 测试与验证

`npm test` 运行 14 组共 63 个测试，覆盖：

- 随机数可复现、空间网格与暴力搜索结果一致、模拟内核里没有 `Math.random`；
- 表型随基因单调变化、交叉与突变、孟德尔比例（Aa × Aa 约 25% 表达）、稀有基因；
- 繁殖条件、能量扣除、世代与亲代、冷却；
- 物质守恒、没有光时植物不长、尸体会分解成营养；
- 饥饿的个体会找到食物、猎物会逃、捕食者会追；
- 灾害有真实影响、灾害总结来自真实数据，并且会扣除灾害之前就已存在的趋势（不会把放牧造成的减少算到一场阵雨头上）；
- 存档往返后与原世界逐步一致；
- 编年史事件只触发一次、统计降采样、图鉴首次出现与回归；
- 谱系剪枝后仍能从后代追溯到被关注的祖先、血脉标签继承、生命故事的持久化、纪录保持者自动归档；
- 两个种子各跑 10 个模拟分钟不会爆炸也不会无故全灭；
- 世界日历在午夜换日。

长时间检查（`npm run sim -- --seed eden --hours 24 --report 120 --watch 3`，默认参数）：

- 连续 24 个模拟小时：消费者始终在 140–198 只之间，掠食者 5–7 只，水草 133–140 株，同时存在 6–8 个族群；
  到第 24 小时繁衍到第 167 代（平均每小时约 7 代）；没有发生总灭绝，也没有触发复苏；约 78% 的死亡是寿终，约 20% 被捕食，约 2% 饿死；物质账本守恒。
- 每个模拟小时关注 3 只生物（共 72 只）：最长的一条血脉被连续追踪了 167 代；谱系只保留了 2893 个节点；
  24 小时后的完整存档约 1.8 MB（其中历史约 1.2 MB），读回后状态一致；Node 进程堆内存约 43 MB。
- 在浏览器里连续推进 2 个模拟小时，JS 堆从 3.7 MB 增长到 6.3 MB 后趋于平稳（各类历史都有上限）。

浏览器检查：`node scripts/snap.mjs` 会启动 `vite preview`，在 1920×1080 等尺寸下截图、测帧率并检查控制台报错。
`--scenario soul` 走查观察卡、档案馆、家族树、图鉴和编年史；`--scenario companion` 检查自动画质、设置、声音、鼠标隐藏和壁纸模式。

## 性能

- 模拟固定每秒 30 步，与帧率无关；渲染用 requestAnimationFrame 插值。无头运行约每秒 1500–3000 步（约 200 只生物）。
- 空间网格查询、辉光贴图缓存、离屏缓存背景、对象池特效、小尺寸生物简化绘制。
- 画质"自动"会根据每帧耗时在低 / 中 / 高三档之间调整（分辨率倍数、焦散、粒子、触须细节）；也可以手动固定。
- 节能模式把渲染限制在每秒 30 帧；壁纸模式默认开启。标签页隐藏时世界和声音都会暂停。

## 已实现

- 第一阶段：可运行的美丽世界——地形、光柱、焦散、微粒、水草、程序化生物与动作、固定步长循环、DPI 和窗口缩放。
- 第二阶段：真正的人工生命——代谢、衰老、死亡与分解、营养循环与账本、交叉突变与稀有基因、求偶与产卵、狩猎、效用 AI、物种分化、家族、基因库与灭绝复苏。
- 第三阶段：观察与干预——选中、投喂、长按、三种食物、五种灾害与自然天气、环境与流速控制、事件日志、统计与趋势图、观察卡、控制坞、IndexedDB 存档与导入导出。
- 第四阶段：三个灵魂功能——生命故事、生命档案馆与纪录保持者、谱系与家族树、继续跟随孩子、编年史筛选、生命图鉴与头像、演化对照与"进化之最"。
- 第五阶段：桌面伴侣——壁纸模式、鼠标自动隐藏、字幕设置、自动画质与节能模式、程序化环境声音、平台适配点、长时间稳定性与存档体积检查。

## 尚未实现

- **真正的系统壁纸**：需要原生外壳（见下）。目前请用 Plash / Lively 这类工具。
- **Web Worker**：补算离开的时间已经在 Worker 里进行，但实时运行的模拟仍在主线程。
- **PWA / Service Worker**：构建产物本身可离线运行，但还没有做成可安装的应用。
- **多语言**：事件以"类型 + 参数"存储，文案集中在叙述模块，但目前只有中文。
- **移动端触控的细致适配**：基本可用，没有专门打磨。

## 设计上的取舍

- 侧视的水族箱剖面：上层光多、底层营养多，自然分出生态位。
- 世界尺寸在创建时按屏幕比例确定（宽高比 1.25–2.6），之后改变窗口只改变镜头，不影响模拟。
- 繁殖投入、代谢、寿命等公式是为"坐着就能看完一只生物的一生、一小时能看到好几代"调出来的，不追求生物学精确。
- 物种是对基因做聚类得出的，会随着分化和灭绝变化；家族沿着发起交配的一方往下传。
- 稀有外观只影响外形、可见度和少量能耗，不提供额外的生存优势，能不能留下来要看运气和选择。
